# O Contexto do Alienista — Cliente Desktop

Interface gráfica do jogo "O Contexto do Alienista", desenvolvida em Python utilizando **Tkinter**.

---

##  Pré-requisitos

* **Python 3.10** ou superior instalado na máquina.
* **Ambiente Virtual (recomendado):** Recomenda-se a utilização de uma `venv` para isolar as dependências do projeto.

---

##  Instalação das Dependências

1. **Abra o terminal** na pasta raiz do projeto.

2. *(Opcional, mas recomendado)* **Crie e ative o ambiente virtual:**
   * **Windows:**
     ```bash
     python -m venv .venv
     .venv\Scripts\activate
     ```
   * **Linux / macOS:**
     ```bash
     python3 -m venv .venv
     source .venv/bin/activate
     ```

3. **Instale as bibliotecas necessárias:**
   ```bash
   pip install customtkinter pillow


##  Como Executar o Jogo
Com o terminal na pasta raiz do projeto (e a venv ativada, se estiver usando), execute o arquivo da interface principal:
     
     python interface_main.py
     
  * A aplicação abrirá diretamente.
